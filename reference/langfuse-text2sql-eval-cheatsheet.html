Langfuse × EasySQL 评测闭环速查表

把 Trace、Dataset、Experiment、Score 和 Prompt Version 映射到 Text2SQL 的最小可运行模型。

对象映射

Langfuse 对象EasySQL 含义必须保存
Trace一轮 Text2SQL 执行session/message、db、mode、模型、git SHA
Observationretrieve、prompt_build、generation、validate、execute输入、输出、耗时、错误、token
Dataset Item一个可重复评测问题question、db、reference SQL/result、expected tables、tags
Experiment Run固定配置的一轮批量回归dataset version、prompt version、model、retrieval hash、git SHA
Score质量证据result equivalence、schema linking、failure category、人工纠正
Prompt Version不可变候选提示词name、version、labels、commit message、config

推荐数据集

easysql-golden-core

30～100 条长期稳定的核心能力样本。

easysql-badcase-regression

经人工审核、已有正确答案的历史失败样本。

easysql-holdout

优化时不查看，发布前才运行，防止对 bad case 过拟合。

Score 配置

名称类型解释
syntax_validBOOLEAN数据库是否接受 SQL 语法
execution_validBOOLEAN只读沙箱中是否可执行
result_equivalentBOOLEAN生成结果是否与参考结果等价
table_recallNUMERIC必要表是否被检索并提供给模型
join_path_coverageNUMERIC必要 JOIN 边覆盖率
failure_categoryCATEGORICALWRONG_JOIN、MISSING_FILTER 等
sql_correctionCORRECTION人工修正后的 SQL
review_noteTEXT业务口径、误判原因和审核说明

发布门禁

  • 候选 Prompt 用明确 version 运行，不用 latest label。
  • 核心集 execution accuracy 不下降。
  • bad-case regression 通过率达到目标。
  • 关键标签如 tenant_filter、payment_status 不允许新增失败。
  • 延迟、token 和 tool call 增长在预算内。
  • holdout 通过后才把 production label 移到候选版本。

三个不要混淆

Dataset 不等于 Few-shot。 Dataset 用于判分；只有经确认的正确案例才可能进一步进入 EasySQL 的 Milvus Few-shot 库。
validation_passed 不等于答案正确。 当前值主要表示 SQL 可解析或可执行计划通过。
Langfuse 不会自动把 bad case 变成更好的 Prompt。 它负责版本、数据、实验、评分和发布证据；优化策略仍由人或自定义优化器决定。
